1. Semantic HTML5 Architecture

Semantic elements convey meaning to both the browser and the developer. They improve search engine ranking, accessibility (screen readers), and code maintainability.

Element Purpose & Best Practice
<header> Introductory content or navigational links for a page or section.
<nav> Designates the primary navigational block of links.
<main> The unique dominant content of the document body. Only one per page.
<section> Thematic grouping of content, typically with a heading.
<article> Self-contained composition that is independently reusable (e.g. course card).
<footer> Footer containing author info, copyright, and auxiliary links.

2. Modern CSS Layouts (Flexbox vs Grid)

Modern CSS eliminates the need for float hacks or heavy layout frameworks.

CSS Flexbox (One-Dimensional)

Ideal for distributing space along a single row or column (e.g., navigation bars, button clusters, form rows).

/* Flexbox Container */
.nav-container {
  display: flex;
  justify-content: space-between; /* Space items evenly */
  align-items: center;            /* Center vertically */
  gap: 1rem;                      /* Spacing between items */
}

CSS Grid (Two-Dimensional)

Ideal for structured multi-column card layouts, dashboard dashboards, and complex page grids.

/* Auto-responsive Card Grid without media queries */
.course-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 1.5rem;
}

3. Vanilla JavaScript DOM Manipulation

Interacting with the Document Object Model using modern standards:

// 1. Selecting Elements
const courseCards = document.querySelectorAll('.course-card');
const submitBtn = document.getElementById('submit-button');

// 2. Event Listeners
submitBtn.addEventListener('click', (event) => {
  event.preventDefault(); // Prevent default page reload
  console.log('Class scheduled successfully!');
});

// 3. Dynamic Element Creation & Safe Insertion
function createNotice(message) {
  const alertBox = document.createElement('div');
  alertBox.className = 'alert-box';
  // Use textContent to prevent XSS vulnerability
  alertBox.textContent = message;
  document.body.appendChild(alertBox);
}
Security Note: Always prefer textContent over innerHTML when inserting user-supplied values into the DOM to guard against Cross-Site Scripting (XSS).

4. Browser LocalStorage (Persistence)

localStorage allows web applications to store key-value pairs in the client browser with no expiration date.

// Saving array data to localStorage
const userCourses = [{ id: '1', title: 'Custom Python 101' }];
localStorage.setItem('my_courses', JSON.stringify(userCourses));

// Retrieving and safely parsing data
try {
  const savedData = localStorage.getItem('my_courses');
  const parsedCourses = savedData ? JSON.parse(savedData) : [];
  console.log(parsedCourses);
} catch (error) {
  console.error('Failed to parse localStorage data:', error);
}

5. Faculty Exam Summary Checklist

  • Always validate inputs on both the client side and server side in production environments.
  • Ensure contrast ratios meet WCAG AA standards (minimum 4.5:1 for standard text).
  • Use relative CSS units like rem, em, and percentages for responsive scalability.
  • Keep JavaScript modular and maintain separation of concerns between structure (HTML), presentation (CSS), and behavior (JS).
